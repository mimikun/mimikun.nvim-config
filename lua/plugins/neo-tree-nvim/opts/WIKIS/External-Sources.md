External sources can be added by first installing the plugin, then referencing it in your config. Each source will have it's own setup instructions on its project page. Below is a listing of known external sources.

[example](https://github.com/nvim-neo-tree/example-source): an example of how build a custom source for [Neo-tree](https://github.com/nvim-neo-tree/neo-tree.nvim) as an external plugin.


[zk](https://github.com/prncss-xyz/neo-tree-zk.nvim): navigate folder-sorted queries from [zk-nvim](https://github.com/mickael-menu/zk-nvim).

[neo-tree-diagnostics](https://github.com/mrbjarksen/neo-tree-diagnostics.nvim): Shows workspace diagnostics in a tree view.

[netman.nvim](https://github.com/miversen33/netman.nvim#neo-tree): Neovim (Lua powered) Network Resource Manager. This is more than just a neo-tree extension but it also includes a source for neo-tree which can enable you to browse remote files.

[neo-tree-tests-source](https://github.com/TimCreasman/neo-tree-tests-source.nvim/tree/1.0.0): Neotest results viewer within neo-tree. You can run and visualize all the tests across your project.
