# Scheme plugins

### [vim-iced-fern-debugger](https://github.com/liquidz/vim-iced-fern-debugger)

vim-iced debugging plugin powered by fern.vim

# Mapping plugins

### [fern-mapping-fzf.vim](https://github.com/LumaKernel/fern-mapping-fzf.vim)

fern.vim plugin for fzf.

### [fern-mapping-reload-all.vim](https://github.com/LumaKernel/fern-mapping-reload-all.vim)

Mapping to reload from root.

### [fern-mapping-collapse-or-leave.vim](https://github.com/hrsh7th/fern-mapping-collapse-or-leave.vim)

The fern plugin for mapping to collapse or leave.

### [fern-mapping-call-function.vim](https://github.com/hrsh7th/fern-mapping-call-function.vim)

The fern plugin to call your custom function.

### [fern-preview.vim](https://github.com/yuki-yano/fern-preview.vim)

The fern plugin to open file preview windows in popup window or floating window.

### [git2.nvim](https://github.com/Freed-Wu/git2.nvim)

The [fern plugin](https://github.com/Freed-Wu/git2.nvim#fernvim) can replace [fern-mapping-git.vim](https://github.com/lambdalisue/fern-mapping-git.vim)
and [fern-git-status.vim](https://github.com/lambdalisue/fern-git-status.vim)
for neovim.

# Render Plugin

### [fern-renderer-web-devicons.nvim](https://github.com/TheLeoP/fern-renderer-web-devicons.nvim)

The fern plugin to add file type icons through [nvim-tree/nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons).
