# nvumi

nvumi is a Neovim plugin that integrates the [numi](https://github.com/nikolaeu/numi) natural language calculator with [snacks.nvim](https://github.com/folke/snacks.nvim) to bring live, natural language calculations directly into your Neovim workflow.

This wiki contains detailed documentation on installation, configuration and usage.
