List of Vimwiki plugins or adviced Vim plugins.

### Plugins

- [chipsenkbeil/vimwiki-server.nvim](https://github.com/chipsenkbeil/vimwiki-server.nvim): a companion plugin to vimwiki that offers experimental features and enhanced functionality on top of the vimwiki language using the `vimwiki-server` to inspect, manipulate, and generate vimwiki content.
- [qadzek/link.vim](https://github.com/qadzek/link.vim): a plugin created to handle long URLs in Vimwiki (Markdown syntax).

### Tools

- [rust-lang/mdBook](https://github.com/rust-lang/mdBook): mdBook is a utility to create modern online books from Markdown files.
- [cobalt-org/cobalt.rs](https://github.com/cobalt-org/cobalt.rs): A straightforward static site generator written in Rust.
- [chipsenkbeil/vimwiki-rs](https://github.com/chipsenkbeil/vimwiki-rs): libraries and tooling written in Rust that enable parsing, inspecting, and manipulating vimwiki content.
